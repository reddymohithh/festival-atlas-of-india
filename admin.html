Add and edit festivals directly in the repository
This page commits straight to your GitHub repository using a personal access token you paste below. The token is stored only in this browser's local storage and is never sent anywhere except api.github.com. Use a fine-grained token scoped to just this one repository with read and write access to Contents, and only sign in here on a device you trust. Anyone with this token can edit the repository, so treat it like a password.
Create one at github.com/settings/personal-access-tokens/new. Choose "Only select repositories" and pick this repo. Under Permissions, set Contents to Read and write. Nothing else is needed.
